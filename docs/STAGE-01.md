# Stage 01 — Frontend Foundation

The project begins with the presentation layer rather than database wiring.

The UI is intentionally designed around the CEC workflow:
Students → Payments → Books & Packages → Inventory → Issue Books → Reports.

The dashboard uses the confirmed 2026/2027 context and represents:
- students
- payments
- book readiness
- outstanding package value
- recent payments
- stock/activity alerts

The current values are demonstration data only. They must be replaced with Google Sheets data in a later stage.

## Design direction

The interface uses:
- restrained institutional blue
- deep navy navigation
- compact data-dense cards
- high-contrast typography
- clear operational status pills
- responsive layouts
- desktop-first office workflow with mobile adaptation

The goal is a purpose-built school operations interface, not a generic SaaS dashboard template.
